# 📖 Glosarium Resmi: Legend of Legaia (PS1) - English & Bahasa Indonesia

Glosarium ini berfungsi sebagai standar rujukan utama untuk menjaga konsistensi istilah game, nama entitas, konsep dunia Legaia, jurus pertarungan, dan item perlengkapan di seluruh skrip terjemahan dan modding.

---

## 1. Entitas & Konsep Dunia Legaia

| Istilah Asli (English) | Terjemahan / Ejaan Resmi | Definisi / Penjelasan Konteks |
| :--- | :--- | :--- |
| **The Mist** | **Kabut** / **Kabut Jahat** | Fenomena mistis mematikan yang merasuki Seru dan menghancurkan peradaban manusia. |
| **Genesis Tree** | **Pohon Genesis** | Pohon keramat sumber kehidupan purba yang mampu mengusir Kabut dan membangkitkan kekuatan Ra-Seru. |
| **Seru** | **Seru** | Makhluk simbiosis misterius yang memberi kekuatan luar biasa pada manusia, namun menjadi buas jika tersentuh Kabut. |
| **Ra-Seru** | **Ra-Seru** | Jenis Seru berkesadaran tinggi dan kebal terhadap Kabut; menjadi mitra para pahlawan (Meta, Terra, Ozma). |
| **Sim-Seru** | **Sim-Seru** | Bentuk Seru raksasa yang menopang struktur pulau atau benteng (misal: Mt. Rim Elm / Juggernaut). |
| **Tenebrous Trees** | **Pohon Kegelapan** | Pohon jahat yang menjadi sumber penyebaran Kabut. |
| **Mist Generator** | **Pembangkit Kabut** | Mesin raksasa ciptaan Cort dan Jette untuk memompa Kabut ke seluruh benua. |
| **Biron** | **Biron** | Ajaran/agama bela diri disiplin pertapaan yang melarang ketergantungan pada Seru. |
| **Hunter** | **Pemburu** | Pekerjaan para pejuang penjaga desa yang berburu monster di luar tembok. |

## 3. Parameter Status & Menu Antarmuka

| Istilah Asli (English) | Padanan Bahasa Indonesia | Keterangan Singkat |
| :--- | :--- | :--- |
| **HP (Hit Points)** | **HP** / **Darah** | Poin nyawa karakter. |
| **MP (Magic Points)** | **MP** / **Poin Sihir** | Poin energi untuk memanggil sihir Seru. |
| **AP (Art Points)** | **AP** / **Poin Jurus** | Poin komando untuk melancarkan serangan Tactical Arts. |
| **Attack** | **Serang** | Perintah dasar menyerang. |
| **Spirit** | **Semangat** | Perintah bertahan, memperpanjang bar komando, dan memulihkan AP. |
| **Magic** | **Sihir** | Memanggil kekuatan Seru yang telah diserap. |
| **Item** | **Barang** | Menggunakan item pemulihan atau pendukung. |
| **Escape** | **Kabur** | Melarikan diri dari pertempuran. |
| **Status** | **Status** | Kondisi fisik dan atribut tempur karakter. |
| **Equip** | **Senjata** / **Pasang** | Memasang perlengkapan tempur. |
| **Config** | **Opsi** / **Pengaturan** | Pengaturan pesan, suara, tombol stik. |
| **Save** | **Simpan** | Menyimpan data permainan ke Memory Card. |

## 4. Status Tempur (Status Ailments)

| Istilah Asli | Padanan Bahasa Indonesia | Efek Tempur |
| :--- | :--- | :--- |
| **Poison** | **Racun** | Kehilangan HP setiap giliran bertarung atau berjalan. |
| **Venom** | **Bisa Mematikan** | Bentuk racun parah dengan pengurangan HP lebih besar. |
| **Numb** | **Lumpuh** | Karakter tidak dapat bergerak dalam beberapa giliran. |
| **Curse** | **Kutukan** | Karakter tidak dapat menggunakan perintah komando tertentu. |
| **Rot** | **Busuk** | Menghalangi fungsi perlengkapan tempur. |
| **Petrify** | **Batu** | Karakter membatu dan tidak dapat bertarung. |
| **Faint / Down** | **Pingsan** / **Tumbang** | HP mencapai 0; tidak dapat bertarung kecuali dihidupkan kembali. |
